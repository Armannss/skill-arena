Every page below was built by the same coding agent from the same brief. The only difference is which design skill it had installed, if any. Toggle blind mode, pick your favourites, then reveal who made them.

Scoreboard

Cost, time and whether the agent actually loaded the skill, across every prompt in this run. A skill can only change the result if the agent loads it, so this also shows whether the brief fits what each skill is made for.

How this was made

  1. Each contender's skills are cloned at a pinned commit and loaded as a plugin, so a run sees exactly one contender.
  2. The agent runs headless in an empty folder outside any project. No user settings, plugins, memory or CLAUDE.md reach it.
  3. The prompt never names a skill. Each skill has to trigger on its own, the way it would for a real user.
  4. Pages are screenshotted in Chrome at 1440 and 390 pixels wide, after one scroll through the page.
